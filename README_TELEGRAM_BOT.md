## 💡 Основные возможности

### Поддерживаемые форматы трек-номеров:
1. **Числовые:** `79023797293946` (10-20 цифр)
2. **China Post:** `LP123456789CN` (буквы-цифры-буквы)
3. **SF Express:** `SF1234567890123` (SF + 13 цифр)
4. **EMS China:** `EA123456789CN` (E + буквы/цифры + CN)
5. **Общий:** любые 10-20 символов (A-Z, 0-9)

### Workflow:
```
Фото → Трек-номер → Автопоиск → Обновление БД → Сохранение → Подтверждение
```
