# Улучшение центрирования фотографий в галерее

## Дата обновления
6 августа 2026, 23:25 UTC-3

## Проблема
- Главное изображение отображалось ближе к левой стороне
- Горизонтальные фото не использовали весь доступный размер окна
- Недостаточное использование пространства экрана

## Решение

### 1. Изменена структура модального окна
Добавлен отдельный контейнер для изображения с flexbox центрированием:

```html
<div class="modal-body" style="display: flex; flex-direction: column;">
  <!-- Контейнер для изображения с центрированием -->
  <div class="d-flex justify-content-center align-items-center">
    <img id="photoModalImage" style="margin: auto;" />
  </div>
  
  <!-- Миниатюры внизу -->
  <div id="photoThumbnails">...</div>
</div>
```

### 2. Обновлены размеры изображения
- **Было:** `max-height: 60vh` (только ограничение по высоте)
- **Стало:** `max-height: 60vh; max-width: 90vw` (ограничение и по высоте, и по ширине)

### 3. Увеличена ширина модального окна
- **Было:** `modal-xl` (по умолчанию ~1140px)
- **Стало:** `modal-xl` с `max-width: 95vw` (95% от ширины экрана)

### 4. Добавлены CSS свойства для правильного отображения
```css
#photoModalImage {
  object-fit: contain;  /* Сохранение пропорций */
  width: auto;          /* Автоматическая ширина */
  height: auto;         /* Автоматическая высота */
  margin: auto;         /* Центрирование */
}
```

## Преимущества

### Для вертикальных фото
- Отображаются по центру модального окна
- Сохраняют пропорции
- Используют максимально доступную высоту (60vh)

### Для горизонтальных фото
- Отображаются по центру
- Используют до 90% ширины экрана
- Автоматически масштабируются
- Занимают весь доступный размер окна

### Для квадратных фото
- Идеально центрированы
- Оптимальный размер

## Технические детали

### Flexbox центрирование
```css
display: flex;
justify-content: center;  /* Горизонтальное центрирование */
align-items: center;      /* Вертикальное центрирование */
```

### Ограничения размера
```css
max-height: 60vh;  /* Максимум 60% высоты окна браузера */
max-width: 90vw;   /* Максимум 90% ширины окна браузера */
```

### Object-fit
```css
object-fit: contain;
/* Изображение масштабируется с сохранением пропорций,
   полностью помещается в контейнер */
```
