# Руководство по Админ-Панели

## 🎯 Обзор системы прав доступа

В системе существует три уровня доступа:

### 1. 👤 Пользователь (обычный)
- ✅ Может авторизоваться в системе
- ✅ Может просматривать заказы
- ✅ Может использовать Telegram бота
- ❌ Не имеет доступа к админ-панели

### 2. 🔧 Администратор
- ✅ Все права обычного пользователя
- ✅ Доступ к админ-панели (`/admin`)
- ✅ Может добавлять обычных пользователей
- ✅ Может активировать/деактивировать пользователей
- ✅ Может удалять пользователей
- ❌ НЕ может назначать администраторов
- ❌ НЕ может назначать суперадминистраторов

### 3. 👑 Суперадминистратор
- ✅ Все права администратора
- ✅ Может назначать обычных администраторов
- ✅ Может назначать других суперадминистраторов
- ✅ Полный контроль над системой

## 🚀 Первоначальная настройка

### Шаг 1: Запустите миграцию

```bash
python migrate_add_superadmin.py
```

Эта команда:
- Добавит поле `is_superadmin` в таблицу `users`
- Преобразует всех существующих администраторов в суперадминистраторов
- Покажет список текущих суперадминов

### Шаг 2: Создайте первого суперадмина (если нужно)

Если у вас еще нет администраторов:

```bash
python create_admin.py
```

Следуйте инструкциям:
1. Выберите "1" - Создать нового суперадминистратора
2. Введите ваш Telegram ID (узнать можно у бота @userinfobot)
3. Опционально: введите номер телефона, имя, фамилию

### Шаг 3: Запустите приложение

```bash
python backend/app.py
```

Или используйте:
```bash
uvicorn backend.app:app --reload
```

## 🎨 Использование админ-панели

### Доступ к админ-панели

1. Откройте браузер и перейдите на `http://localhost:8000/login`
2. Нажмите "Login with Telegram"
3. Авторизуйтесь через Telegram
4. Перейдите на `http://localhost:8000/admin`

### Статистика

В верхней части панели отображается:
- 📊 **Всего пользователей** - общее количество
- ✅ **Активных** - пользователи с `is_active=1`
- 👑 **Суперадминов** - пользователи с `is_superadmin=1`
- 🔧 **Администраторов** - пользователи с `is_admin=1`

### Добавление пользователя

1. Нажмите кнопку **"Добавить пользователя"**
2. Заполните поля:
   - **Telegram ID** (обязательно) - ID пользователя в Telegram
   - **Номер телефона** (опционально)
   - **Имя** (опционально)
   - **Фамилия** (опционально)
   - **☑️ Администратор** - если хотите дать права администратора
   - **☑️ Суперадминистратор** - если хотите дать права суперадмина (только для суперадминов)

3. Нажмите **"Добавить"**

> **Примечание:** Checkbox "Суперадминистратор" виден только суперадминистраторам

### Редактирование пользователя

1. Нажмите на кнопку **✏️** (редактировать) рядом с пользователем
2. Измените нужные поля
3. Нажмите **"Сохранить"**

> **Ограничения:**
> - Обычные администраторы могут редактировать только номер телефона
> - Суперадминистраторы могут изменять все поля, включая права доступа

### Деактивация пользователя

1. Нажмите на кнопку **🚫** (деактивировать) рядом с пользователем
2. Подтвердите действие

Деактивированный пользователь:
- Не сможет войти в систему
- Будет помечен бейджем "Неактивен" (красный)

Чтобы активировать обратно - нажмите ту же кнопку (она станет **✅**)

### Удаление пользователя

1. Нажмите на кнопку **🗑️** (удалить) рядом с пользователем
2. Подтвердите действие

> **Внимание:** Удаление окончательное и не может быть отменено!

## 🎯 Типичные сценарии использования

### Сценарий 1: Добавить сотрудника для работы с заказами

Вы хотите дать доступ новому сотруднику, чтобы он мог просматривать заказы и использовать бота.

1. Откройте админ-панель
2. Нажмите "Добавить пользователя"
3. Введите Telegram ID сотрудника
4. Заполните имя (опционально)
5. **НЕ ставьте** галочки "Администратор" или "Суперадминистратор"
6. Нажмите "Добавить"

✅ Сотрудник сможет войти и работать с заказами, но не будет иметь доступа к админ-панели.

### Сценарий 2: Назначить менеджера (администратора)

Вы хотите дать сотруднику возможность добавлять других пользователей.

1. Откройте админ-панель
2. Нажмите "Добавить пользователя"
3. Введите Telegram ID
4. **Поставьте галочку** "Администратор"
5. **НЕ ставьте галочку** "Суперадминистратор"
6. Нажмите "Добавить"

✅ Сотрудник сможет:
- Входить в админ-панель
- Добавлять обычных пользователей
- Управлять пользователями

❌ Но НЕ сможет:
- Назначать администраторов
- Назначать суперадминистраторов

### Сценарий 3: Назначить второго владельца (суперадмина)

Вы хотите дать полный доступ другому человеку.

> **Важно:** Это может сделать только суперадминистратор!

1. Откройте админ-панель (как суперадмин)
2. Нажмите "Добавить пользователя"
3. Введите Telegram ID
4. **Поставьте галочку** "Суперадминистратор"
5. Нажмите "Добавить"

✅ Новый суперадминистратор получит полные права, включая возможность назначать других суперадминов.

## 🔒 Безопасность

### Получение Telegram ID

Чтобы узнать свой Telegram ID:
1. Откройте Telegram
2. Найдите бота: `@userinfobot`
3. Отправьте `/start`
4. Бот ответит вашим ID

> **Важно:** Добавляйте в систему только тех людей, которым вы доверяете!

### Рекомендации

1. **Не делайте всех суперадминистраторами**
   - Суперадминистраторами должны быть только владельцы бизнеса
   - Для обычных менеджеров достаточно прав администратора

2. **Деактивируйте пользователей при увольнении**
   - Не удаляйте сразу, сначала деактивируйте
   - Это сохранит историю, но заблокирует доступ

3. **Регулярно проверяйте список пользователей**
   - Раз в месяц просматривайте список
   - Удаляйте неиспользуемые аккаунты

## 🆘 Устранение неполадок

### Проблема: Не могу войти в систему

**Решение:**
1. Убедитесь, что ваш Telegram ID добавлен в базу данных
2. Проверьте, что вы не деактивированы (is_active=1)
3. Проверьте логи приложения

### Проблема: Не вижу кнопку "Суперадминистратор"

**Причина:** Вы не являетесь суперадминистратором.

**Решение:**
1. Попросите текущего суперадминистратора назначить вас
2. Или запустите `create_admin.py` для создания нового суперадмина

### Проблема: Ошибка "Недостаточно прав"

**Причина:** Вы пытаетесь выполнить действие, требующее более высоких прав.

**Решение:**
- Обычный администратор не может назначать других администраторов
- Попросите суперадминистратора выполнить это действие

### Проблема: После деплоя нет суперадминов

**Решение:**
1. Запустите миграцию:
   ```bash
   python migrate_add_superadmin.py
   ```
2. Или создайте нового:
   ```bash
   python create_admin.py
   ```

## 🎓 Часто задаваемые вопросы

### В чем разница между администратором и суперадминистратором?

**Администратор:**
- Может добавлять обычных пользователей
- Может управлять пользователями (деактивировать, удалять)
- НЕ может назначать администраторов

**Суперадминистратор:**
- Все права администратора
- Может назначать администраторов
- Может назначать суперадминистраторов

### Могу ли я понизить права суперадминистратора?

Да, если вы сами суперадминистратор:
1. Нажмите ✏️ рядом с пользователем
2. Снимите галочку "Суперадминистратор"
3. Сохраните

> **Внимание:** Нельзя понизить права самому себе!

### Что произойдет, если не останется ни одного суперадмина?

Если вы случайно удалите или деактивируете всех суперадминов:
1. Никто не сможет управлять администраторами
2. Придется запустить `create_admin.py` заново

**Рекомендация:** Всегда держите минимум 2 суперадминистраторов!

### Нужно ли теперь запускать create_admin.py при каждом деплое?

**НЕТ!** Теперь вы можете:
1. Один раз создать суперадмина через `create_admin.py`
2. В дальнейшем назначать пользователей через админ-панель
3. При деплое суперадмины сохранятся в базе данных

## 📝 Изменения в системе

### Что было раньше
- Поле `is_admin` (0 или 1)
- Приходилось запускать `create_admin.py` при каждом деплое
- Не было разграничения прав между администраторами

### Что теперь
- Три уровня доступа: пользователь, администратор, суперадминистратор
- Можно назначать администраторов через веб-интерфейс
- Суперадминистраторы могут назначать других суперадминов
- База данных сохраняется между деплоями

## 🔄 Миграция существующих данных

При запуске миграции (`migrate_add_superadmin.py`):
- Все существующие администраторы (`is_admin=1`) автоматически станут суперадминистраторами
- Обычные пользователи останутся обычными пользователями
- Это безопасная операция, откат не требуется
