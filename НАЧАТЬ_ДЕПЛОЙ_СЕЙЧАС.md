### Создайте первого суперадмина

1. **Откройте Shell в Render**
   - В Dashboard → ваш сервис
   - Нажмите "Shell" (справа вверху)

2. **Запустите команду:**
   ```bash
   python create_admin.py
   ```

3. **Следуйте инструкциям:**
   - Выберите "1" - Создать нового суперадминистратора
   - Введите ваш Telegram ID
   - Введите имя (опционально)

**Получить Telegram ID:**
- Откройте Telegram
- Найдите бота `@userinfobot`
- Отправьте `/start`
- Скопируйте ваш ID

### Проверьте работу

1. Откройте ваш сайт:
   ```
   https://mysyte-web.onrender.com/login
   ```

2. Нажмите "Login with Telegram"

3. Авторизуйтесь

4. Перейдите в админ-панель:
   ```
   https://mysyte-web.onrender.com/admin
   ```

**Должны увидеть:**
- ✅ Статистику с суперадминами
- ✅ Кнопку "Добавить пользователя"

## 🆘 Если что-то пошло не так

### Деплой завис или упал

**Проверьте логи:**
- Render Dashboard → Logs
- Найдите красный текст (ошибка)

**Частые проблемы:**
1. Отсутствует файл → проверьте `git add .`
2. Ошибка Python → проверьте syntax в измененных файлах
3. База данных → миграция запустится заново при следующем деплое

**Решение:**
```bash
# Если нужно, сделайте коррекцию
# Затем заново:
git add .
git commit -m "Fix: исправление ошибки"
git push origin main
```

### Не могу войти после деплоя

**Причина:** Суперадмин не создан

**Решение:**
1. Render Dashboard → Shell
2. `python create_admin.py`
3. Создайте суперадмина

### Миграция не запустилась

**Проверьте логи** - есть ли строка "Running migrations..."?

**Если нет, запустите вручную:**
```bash
# Через Render Shell
python migrate_add_superadmin.py
```
