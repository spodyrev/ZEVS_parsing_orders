# 🔍 Как найти правильный API запрос Taobao

## Проблема
Ты нажимаешь "Синхронизировать заказы", но ничего не происходит. Возможно, был выбран неправильный API эндпоинт.

---

## ✅ Признаки ПРАВИЛЬНОГО запроса

Правильный запрос должен содержать:

### 1. URL должен быть точно таким:
```
https://h5api.m.taobao.com/h5/mtop.taobao.order.queryboughtlistv2/1.0/
```

**Важно:**
- ✅ `h5api.m.taobao.com` - мобильное API
- ✅ `mtop.taobao.order.queryboughtlistv2` - именно этот метод
- ❌ НЕ `buyertrade.taobao.com`
- ❌ НЕ HTML страницы

### 2. Метод запроса:
```
GET (не POST!)
```

### 3. Параметры в URL должны включать:
```
?jsv=2.7.2
&appKey=12574478
&t=1786046727988         (timestamp)
&sign=...                 (MD5 hash)
&api=mtop.taobao.order.queryboughtlistV2    ← ВАЖНО!
&data={"queryType":"all","page":1,"pageSize":15}
```

### 4. Response (ответ) должен содержать JSON:
```json
{
  "api": "mtop.taobao.order.queryboughtlistv2",
  "data": {
    "data": {
      "shopInfo_3316521288174009384": { ... },
      "orderItemInfo_...": { ... }
    }
  }
}
```

## 📋 Пошаговая инструкция

### Шаг 1: Открой Taobao в Chrome
```
1. Открой https://www.taobao.com
2. Войди в свой аккаунт
3. НЕ закрывай это окно!
```

### Шаг 2: Открой DevTools
```
Нажми F12 (или Cmd+Option+I на Mac)
```

### Шаг 3: Настрой фильтры в Network
```
┌─────────────────────────────────────────────────────────┐
│ Elements  Console  Sources  [Network] ◄── Кликни сюда  │
├─────────────────────────────────────────────────────────┤
│ 🔍 Filter  🚫 Clear  [All] [Fetch/XHR] ◄── Кликни сюда │
├─────────────────────────────────────────────────────────┤
│                                                          │
│ ▼ Здесь будут запросы                                  │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

**Действие:**
1. Кликни на вкладку **Network**
2. Кликни на фильтр **Fetch/XHR**
3. Нажми кнопку **Clear** (🚫) чтобы очистить все запросы

### Шаг 4: Перейди на страницу заказов
```
1. Кликни на "我的淘宝" (Мой Taobao) в правом верхнем углу
2. Выбери "已买到的宝贝" (Купленные товары)
3. Дождись загрузки страницы
```

### Шаг 5: Найди правильный запрос
В списке запросов найди строку, которая содержит:
```
queryboughtlistv2
```

**Должно выглядеть так:**
```
┌──────────────────────────────────────────────────────┐
│ Name                              Status  Type  Size │
├──────────────────────────────────────────────────────┤
│ main.js                           200     js    25KB│
│ queryboughtlistv2?jsv=2.7.2...    200     xhr   45KB│ ◄── ЭТО!
│ style.css                         200     css   12KB│
└──────────────────────────────────────────────────────┘
```

### Шаг 6: Проверь, что это правильный запрос

**Кликни на найденную строку `queryboughtlistv2`**

Справа откроется панель. Проверь:

#### A. Вкладка "Headers":
```
General:
  Request URL: https://h5api.m.taobao.com/h5/mtop.taobao.order.queryboughtlistv2/1.0/?...
  Request Method: GET
  Status Code: 200

Query String Parameters:
  ✅ api: mtop.taobao.order.queryboughtlistV2
  ✅ appKey: 12574478
  ✅ t: 1786046727988
  ✅ sign: 8190052c96db59049a2c631b83e0a767
  ✅ data: {"queryType":"all","page":1,"pageSize":15}
```

#### B. Вкладка "Response":
Должен быть JSON, который начинается так:
```json
{
  "api": "mtop.taobao.order.queryboughtlistv2",
  "v": "1.0",
  "ret": ["SUCCESS::调用成功"],
  "data": {
    "data": {
      "shopInfo_3316521288174009384": {
```

**Если видишь такой JSON - это ПРАВИЛЬНЫЙ запрос!** ✅

## ❌ Неправильные запросы (НЕ эти!)

### 1. HTML страницы:
```
❌ https://buyertrade.taobao.com/trade/itemlist/list_bought_items.htm
   Тип: document (не xhr!)
   Response: HTML код страницы
```

### 2. Другие API методы:
```
❌ mtop.order.queryorder
❌ mtop.user.getinfo
❌ mtop.trade.detail
```

### 3. Запросы с ошибками:
```
❌ Status: 400, 401, 403, 500
❌ Response: {"ret":["FAIL::..."]}
```

## 🎯 Как скопировать правильный запрос

### Способ 1: Copy as cURL (Рекомендуется)
```
1. Найди правильный запрос queryboughtlistv2
2. Кликни ПРАВОЙ кнопкой мыши
3. Copy → Copy as cURL (bash)
4. Вставь в текстовый файл
```

Должно получиться так:
```bash
curl 'https://h5api.m.taobao.com/h5/mtop.taobao.order.queryboughtlistv2/1.0/?jsv=2.7.2&appKey=12574478&t=1786046727988&sign=...' \
  -H 'accept: application/json' \
  -H 'cookie: _tb_token_=...' \
  ...
```

### Способ 2: Copy Response (для JSON)
```
1. Кликни на вкладку "Response"
2. Увидишь JSON
3. Кликни ПРАВОЙ кнопкой в области JSON
4. Select All (Cmd+A)
5. Copy (Cmd+C)
6. Вставь в файл
```

## 🔍 Дополнительная проверка

### Если запросов много и непонятно какой нужен:

1. **Очисти Network** (кнопка 🚫 Clear)
2. **Обнови страницу** заказов (F5 или Cmd+R)
3. **Посмотри на запросы**
4. **Найди самый БОЛЬШОЙ XHR запрос** (по размеру Size)
   - Обычно это 30-100 KB
   - Это и есть список заказов

### Альтернативный способ - поиск:
```
1. В поле Filter (🔍) введи: querybought
2. Останутся только нужные запросы
```

## 🆘 Если ничего не работает

### Проблема 1: Нет запроса queryboughtlistv2
**Причина:** Страница использует другой API

**Решение:**
1. Полностью перезагрузи страницу (Shift+F5)
2. Или перейди по прямой ссылке:
   ```
   https://buyertrade.taobao.com/trade/itemlist/list_bought_items.htm
   ```
3. Или открой в режиме инкогнито

### Проблема 2: Status 401 или 403
**Причина:** Не авторизован или истекла сессия

**Решение:**
1. Разлогинься с Taobao
2. Войди заново
3. Повтори шаги

### Проблема 3: Response пустой или ошибка
**Причина:** Нет заказов или проблема с API

**Решение:**
1. Проверь, что у тебя есть заказы в аккаунте
2. Попробуй изменить фильтр заказов (все / ожидают отправки / и т.д.)
3. Каждый раз смотри, какой запрос уходит

## ✅ Чеклист правильного запроса

Проверь, что у тебя:
- [ ] URL: `h5api.m.taobao.com`
- [ ] Метод: `GET`
- [ ] Параметр `api=mtop.taobao.order.queryboughtlistV2`
- [ ] Status: `200`
- [ ] Response Type: `json` (не `html`!)
- [ ] В Response есть `shopInfo_...` объекты
- [ ] Видишь названия своих товаров

Если все галочки стоят - запрос **ПРАВИЛЬНЫЙ**! ✅
