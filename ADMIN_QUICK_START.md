# 🚀 Быстрый старт с админ-панелью

## Первоначальная настройка (один раз)

### 1. Запустите миграцию
```bash
python migrate_add_superadmin.py
```

### 2. Создайте первого суперадмина
```bash
python create_admin.py
```

**Получить свой Telegram ID:**
1. Откройте Telegram
2. Найдите бота: `@userinfobot`
3. Отправьте `/start`
4. Скопируйте ваш ID

---

## После каждого деплоя

### Ничего не нужно делать! 🎉

Все данные сохраняются в базе данных.

**Если нужно добавить пользователей:**
1. Откройте `http://your-domain.com/login`
2. Войдите через Telegram
3. Перейдите на `http://your-domain.com/admin`
4. Добавляйте пользователей через веб-интерфейс

---

## Три уровня доступа

| Роль | Права |
|------|-------|
| **Пользователь** | Работа с заказами, бот |
| **Администратор** | + Управление пользователями |
| **Суперадминистратор** | + Назначение админов |

---

## Добавление пользователей

### Через веб-интерфейс (рекомендуется)
1. `/admin` → "Добавить пользователя"
2. Введите Telegram ID
3. Выберите роль
4. Сохраните

### Через командную строку (только суперадмины)
```bash
python create_admin.py
```

## Структура прав

```
Суперадминистратор (is_superadmin=1, is_admin=1)
├── Полный доступ к админ-панели
├── Может назначать суперадминов
└── Может назначать администраторов

Администратор (is_admin=1, is_superadmin=0)
├── Доступ к админ-панели
├── Может добавлять пользователей
└── НЕ может назначать администраторов

Пользователь (is_admin=0, is_superadmin=0)
├── Доступ к системе заказов
└── Может использовать бота
```

## Решение проблем

### Не могу войти
```bash
# Проверьте, что пользователь есть в БД
python create_admin.py  # опция 2

# Если нет - добавьте
python create_admin.py  # опция 1
```

### Потерял доступ администратора
```bash
# Создайте нового суперадмина
python create_admin.py
```

### База данных пустая после деплоя
```bash
# Запустите миграцию
python migrate_add_superadmin.py

# Создайте суперадмина
python create_admin.py
```

## Безопасность

✅ **Делайте:**
- Храните минимум 2 суперадминов
- Деактивируйте, а не удаляйте пользователей
- Давайте минимально необходимые права

❌ **Не делайте:**
- Не делайте всех суперадминами
- Не делитесь Telegram ID с третьими лицами
- Не удаляйте последнего суперадмина
