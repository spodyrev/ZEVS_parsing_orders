# Функция миниатюр фотографий

## Описание
Добавлена возможность просмотра миниатюр всех фотографий заказа под главным изображением в галерее. Пользователь может кликать на миниатюры для быстрого переключения между фото.

## Что было добавлено

### 1. Контейнер для миниатюр
В модальное окно добавлен новый блок `#photoThumbnails`, который отображается под главным изображением.

### 2. Генерация миниатюр
Функция `generateThumbnails()` автоматически создает миниатюры для всех фото заказа:
- Размер миниатюры: 80x80 пикселей
- Номер фото в правом нижнем углу
- Активная миниатюра выделена синей рамкой
- Hover эффект при наведении мыши

### 3. Интерактивность
- **Клик по миниатюре** - переключение на соответствующее фото
- **Hover** - серая рамка при наведении
- **Активное состояние** - синяя рамка и свечение
- **Плавная прокрутка** - если много фото, миниатюры прокручиваются горизонтально

### 4. Визуальные улучшения
- Красивая прокрутка с кастомным scrollbar
- Плавные переходы и анимации
- Адаптивный дизайн

## Как это выглядит

### Одно фото
Если у заказа только одно фото - миниатюры не показываются.

### Несколько фото (2-10)
Миниатюры отображаются в ряд под главным изображением:

```
┌────────────────────────────────┐
│                                │
│      Главное изображение       │
│                                │
└────────────────────────────────┘
┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐
│ 1 │ │ 2 │ │ 3 │ │ 4 │ │ 5 │  ← Миниатюры (кликабельны)
└───┘ └───┘ └───┘ └───┘ └───┘
  ↑ 
Синяя рамка - активное фото
```

### Много фото (10+)
Миниатюры прокручиваются горизонтально:

```
┌────────────────────────────────┐
│                                │
│      Главное изображение       │
│                                │
└────────────────────────────────┘
◄ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ►
  │ 1 │ │ 2 │ │ 3 │ │ 4 │ │ 5 │  
  └───┘ └───┘ └───┘ └───┘ └───┘
  ← Прокрутка влево/вправо →
```

## Технические детали

### Структура миниатюры
```html
<div class="photo-thumbnail" style="...">
  <img src="/api/orders/{orderId}/warehouse-photo/{index}" />
  <div class="badge bg-dark position-absolute">1</div>
</div>
```

### Стили миниатюры
```css
.photo-thumbnail {
  width: 80px;
  height: 80px;
  cursor: pointer;
  border: 3px solid transparent;
  border-radius: 8px;
  transition: all 0.3s ease;
}

/* Активная миниатюра */
border: 3px solid #0d6efd;
box-shadow: 0 0 10px rgba(13, 110, 253, 0.5);

/* Hover */
border: 3px solid #6c757d;
transform: scale(1.05);
```

### JavaScript функции

#### generateThumbnails()
Создает миниатюры для всех фото текущего заказа:
- Генерирует DOM элементы
- Добавляет обработчики событий (click, hover)
- Подсвечивает активную миниатюру

#### Обновление при навигации
При переключении фото (стрелками или клавиатурой) миниатюры автоматически обновляются:
```javascript
function showPhoto() {
  // ... загрузка фото ...
  generateThumbnails(); // Обновление миниатюр
}
```

## Использование

### Для пользователя
1. Откройте заказ с несколькими фотографиями
2. Кликните на фото со склада
3. Под главным изображением увидите миниатюры
4. Кликайте на миниатюры для переключения между фото
5. Используйте стрелки ← → или клавиатуру для навигации

### Для разработчика
Миниатюры генерируются автоматически, не требуют настройки.

Если нужно изменить размер миниатюр:
```javascript
// В функции generateThumbnails()
thumbDiv.style.cssText = `
    width: 100px;  // ← изменить здесь
    height: 100px; // ← и здесь
    ...
`;
```

## Производительность

### Оптимизация загрузки
- Миниатюры загружаются тем же API endpoint, что и главное изображение
- Браузер кеширует изображения
- При повторном просмотре - мгновенная загрузка

### Рекомендации
- Оптимально для 2-20 фотографий
- При 20+ фото может быть небольшая задержка при первой загрузке
- Горизонтальная прокрутка работает плавно даже для 50+ миниатюр
