# Компактная панель статистики

## Обзор
Переработка больших статистических карточек в компактные информационные блоки в стиле Tesla.

## Дата внедрения
6 августа 2026, 23:50 UTC-3

---

## 🎯 Проблема

### ДО (большие карточки):
```
┌────────────────┐ ┌────────────────┐ ┌────────────────┐ ┌────────────────┐
│ Всего заказов  │ │    В пути      │ │  Доставлено    │ │   Создано      │
│                │ │                │ │                │ │                │
│      42        │ │      15        │ │      20        │ │       7        │
│                │ │                │ │                │ │                │
└────────────────┘ └────────────────┘ └────────────────┘ └────────────────┘
    ← 4 больших карточки занимают много места
```

**Проблемы:**
- 🔴 Слишком большие (height ~150px)
- 🔴 Занимают много вертикального пространства
- 🔴 Огромные цифры (48px)
- 🔴 Лишний padding
- 🔴 Информация слишком разнесена

---

## ✅ Решение (компактная панель)

### ПОСЛЕ:
```
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│   42   │ │   15   │ │   20   │ │   7    │
│ ВСЕГО  │ │ В ПУТИ │ │ДОСТАВЛ.│ │СОЗДАНО │
└────────┘ └────────┘ └────────┘ └────────┘
    ← 4 компактных блока, минималистично
```

**Преимущества:**
- ✅ Компактные (height ~80px)
- ✅ Экономия пространства (-50%)
- ✅ Оптимальный размер цифр (28px)
- ✅ Минимальный padding
- ✅ Быстрое визуальное сканирование

## 🎨 Визуальные характеристики

### Размеры

| Элемент | Было | Стало | Изменение |
|---------|------|-------|-----------|
| Высота карточки | ~150px | ~80px | **-47%** |
| Размер цифры | 48px | 28px | **-42%** |
| Размер текста | 14px | 11px | **-21%** |
| Padding | 28px 24px | 16px 24px | **-43%** |
| Ширина | 25% (col-3) | 140px min | Гибкая |

### Цвета и состояния

#### Обычное состояние:
```
Фон: Белый (#ffffff)
Рамка: Светло-серая (rgba(23, 26, 32, 0.08))
Тень: Легкая (0 2px 6px)
```

#### Hover:
```
Transform: translateY(-2px)  ← Поднимается
Тень: Усиленная (0 6px 12px)
Верхняя полоска: Появляется (scaleX: 0 → 1)
```

#### Цветовое кодирование:
```css
.stat-warning::before { background: #fbbf24; }  /* Желтый - В пути */
.stat-success::before { background: #00b74f; }  /* Зеленый - Доставлено */
.stat-info::before { background: #3e6ae1; }     /* Синий - Создано */
```

## 🎭 Анимации

### 1. Hover эффект
```css
.stat-card:hover {
    transform: translateY(-2px);
    box-shadow: 0 6px 12px rgba(23, 26, 32, 0.12);
}
```
**Результат:** Карточка плавно поднимается на 2px

### 2. Цветная полоска сверху
```css
.stat-card::before {
    content: '';
    position: absolute;
    top: 0;
    width: 100%;
    height: 2px;
    transform: scaleX(0);
    transition: transform 0.3s ease;
}

.stat-card:hover::before {
    transform: scaleX(1);
}
```
**Результат:** При наведении появляется цветная линия сверху

## 🎯 Философия дизайна

### Tesla Принципы

#### 1. Минимализм
```
"Убрать все лишнее, оставить только необходимое"
- Большой padding → Компактный padding
- Огромные цифры → Оптимальный размер
- Много текста → Минимум текста
```

#### 2. Функциональность
```
"Информация должна быть доступна быстро"
- Меньше места → Больше контента на экране
- Быстрое сканирование глазами
- Цветовое кодирование для мгновенного распознавания
```

#### 3. Элегантность
```
"Красота через простоту"
- Чистые линии
- Тонкие тени
- Плавные анимации
- Монохромная палитра с цветными акцентами
```
