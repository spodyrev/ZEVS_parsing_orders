## 🔍 API Details

### Endpoint для деталей заказа
```
POST https://h5api.m.taobao.com/h5/mtop.taobao.order.query.detailv2/1.0/
```

### Параметры
```json
{
  "bizOrderId": "3316188865004009384"
}
```

### Путь к данным в ответе

**Трек-номер:**
```
data.data.logisticsPackages.fields.packageInfos[0].mailNo
```

**Компания доставки:**
```
data.data.logisticsPackages.fields.packageInfos[0].companyInfos[0].companyName
```

**Статус доставки:**
```
data.data.logisticsAddress_{orderId}.fields.logisticsData.status
```

## ⚠️ Важные примечания

### Когда трек-номера может не быть:

1. **Товар еще не отправлен** - продавец не отправил посылку
2. **Продавец не внес трек-номер** - иногда продавцы забывают
3. **Самовывоз** - если выбран самовывоз, трек-номера не будет
4. **Цифровой товар** - для цифровых товаров нет доставки

Это нормально и не является ошибкой!

### Частота обновления

- **Новые заказы**: Синхронизируются при нажатии "Синхронизировать"
- **Трек-номера**: Обновляются при запуске `update_tracking_numbers.py`

Рекомендуется:
1. Раз в день запускать синхронизацию заказов
2. После синхронизации запускать обновление трек-номеров

## 🐛 Проблемы и решения

### Ошибка: "Cookies не найдены"
**Решение:** Запусти `python3 auth_taobao.py`

### Ошибка: "API вернул неуспешный статус"
**Решение:** Cookies истекли, нужна повторная авторизация

### Трек-номера не отображаются
**Причины:**
1. Не запущен `update_tracking_numbers.py`
2. Товар еще не отправлен
3. База данных не обновлена (перезапусти сервер)

**Решение:**
```bash
# Проверь наличие трек-номеров в БД
cd backend
python3 -c "from database import SessionLocal; from models import Order; db = SessionLocal(); print(f'Трек-номеров в БД: {db.query(Order).filter(Order.tracking_number.isnot(None)).count()}')"
```
