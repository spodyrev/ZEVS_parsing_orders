# Быстрый старт - Работа с реальной корзиной Taobao

## 📋 Шаг 1: Авторизация на Taobao

### 1.1 Запустите скрипт авторизации

В терминале выполните:

```bash
cd /Users/macprospodyrev/Projects/MySyte
source venv/bin/activate
python3 auth_taobao.py
```

### 1.2 Что произойдет:

1. Откроется браузер Chrome
2. Загрузится страница входа Taobao
3. **Вам нужно будет:**
   - Войти в свой аккаунт Taobao
   - Перейти на страницу "Мои заказы"
   - Убедиться, что видите свои заказы
   - Вернуться в терминал и нажать Enter

### 1.3 Проверка cookies

Скрипт сохранит cookies в файл `taobao_cookies.json` и покажет:

```
✅ Cookies сохранены
   Количество cookies: XX

🔑 Важные cookies найдены:
   ✅ _tb_token_
   ✅ cookie2
   ✅ t
   ✅ _m_h5_tk
   ✅ unb
```

Все 5 важных cookies должны быть найдены!

## 📋 Шаг 3: Синхронизация заказов

Нажмите кнопку **"Синхронизировать"** в правом верхнем углу

### 3.2 Что произойдет:

В терминале вы увидите:

```

Запрос к API: https://h5api.m.taobao.com/...
Найдено X заказов в ответе API
Успешно распарсено X заказов
✅ Синхронизация завершена
```

### 3.3 Проверка результата

В веб-интерфейсе появится таблица **"Мои заказы"** со всеми вашими заказами из Taobao!

## 📋 Что вы увидите в таблице

| Колонка | Описание |

## 🐛 Возможные проблемы

### Проблема: "Cookies не найдены"

**Решение:**
```bash
# Удалите старые cookies
rm taobao_cookies.json

# Повторите авторизацию
python3 auth_taobao.py
```

### Проблема: "API вернул ошибку"

**Причина:** Cookies устарели

**Решение:**
1. Удалите `taobao_cookies.json`
2. Повторите авторизацию
3. Перезапустите сервер

### Проблема: "Заказы не отображаются"

**Решение:**
1. Проверьте логи в терминале
2. Убедитесь, что в вашем аккаунте Taobao есть заказы
3. Попробуйте синхронизировать еще раз

### Проблема: "Китайские символы не отображаются"

**Решение:** 
Уже исправлено! UTF-8 кодировка настроена правильно.

## 📊 Дополнительные возможности

### API эндпоинты

```bash
# Получить все заказы в JSON
curl http://localhost:8000/api/orders

# Получить статистику
curl http://localhost:8000/api/stats

# Ручная синхронизация через API
curl -X POST http://localhost:8000/api/sync
```

### Фильтрация заказов

В веб-интерфейсе используйте кнопки:
- **Все** - показать все заказы
- **Созданы** - только созданные
- **Оплачены** - только оплаченные  
- **В пути** - отправленные заказы
- **Доставлены** - доставленные заказы

3. **Настройте интервал синхронизации:**
   - Откройте `.env`
   - Измените `SYNC_INTERVAL_HOURS=2` на нужное значение
