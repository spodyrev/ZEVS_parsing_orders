# Исправление ошибки "Bot domain invalid"

## Проблема
При открытии страницы логина вместо кнопки "Войти через Telegram" показывается ошибка:
**"Bot domain invalid"**

## Причина
В настройках Telegram бота не указан домен, с которого разрешена авторизация через Login Widget.

## Решение

### Шаг 1: Откройте @BotFather в Telegram

1. Найдите бота **@BotFather** в Telegram
2. Отправьте команду `/mybots`
3. Выберите вашего бота: **@ZEVS_Parsing_orders_bot**

### Шаг 2: Настройте домен

1. Нажмите **"Bot Settings"**
2. Нажмите **"Domain"**
3. Введите домен: `127.0.0.1:9000`
4. Подтвердите

### Альтернативный способ (через команду):

Отправьте @BotFather команду:
```
/setdomain
```

Затем:
1. Выберите бота: **@ZEVS_Parsing_orders_bot**
2. Введите домен: `127.0.0.1:9000`

### Шаг 3: Обновите страницу

После настройки домена:
1. Обновите страницу логина в браузере (F5 или Cmd+R)
2. Должна появиться кнопка "Войти через Telegram"

---

## Важно!

### Для локальной разработки:
- Домен: `127.0.0.1:9000` или `localhost:9000`

### Для продакшена (после деплоя):
- Нужно будет указать ваш настоящий домен
- Например: `yourdomain.com`
- Или IP адрес вашего сервера

---

## Проверка

После настройки домена на странице логина должно быть:
- ✅ Кнопка "Войти через Telegram" (синяя)
- ❌ НЕ должно быть сообщения "Bot domain invalid"

---

## Дополнительные варианты доменов для локальной разработки

Попробуйте указать один из этих вариантов:
1. `127.0.0.1:9000`
2. `localhost:9000`
3. `127.0.0.1` (без порта)
4. `localhost` (без порта)

Если один не работает - попробуйте другой.

---

## Что делать если не помогло?

1. **Проверьте имя бота в коде:**
   - Откройте `frontend/templates/login.html`
   - Найдите строку: `data-telegram-login="ZEVS_Parsing_orders_bot"`
   - Убедитесь что имя совпадает с именем вашего бота

2. **Проверьте токен бота:**
   - Откройте `.env`
   - Проверьте что `TELEGRAM_BOT_TOKEN` правильный
   - Токен должен быть от @BotFather для бота @ZEVS_Parsing_orders_bot

3. **Перезапустите приложение:**
   ```bash
   # Остановите текущий процесс
   lsof -ti:9000 | xargs kill
   
   # Запустите заново
   cd /Users/macprospodyrev/Projects/MySyte
   PORT=9000 /Users/macprospodyrev/Projects/MySyte/venv/bin/python3 backend/app.py
   ```
