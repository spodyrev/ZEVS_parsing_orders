### ВАРИАНТ 2: Ручной (если нужен контроль)

#### Шаг 1: GitHub (2 минуты)

```bash
# 1. Создайте репозиторий на https://github.com/new
#    Название: MySyte
#    Private/Public: на выбор
#    НЕ добавляйте README, .gitignore

# 2. Push кода
cd /Users/macprospodyrev/Projects/MySyte
git remote add origin https://github.com/ВАШ_USERNAME/MySyte.git
git branch -M main
git push -u origin main

# При запросе пароля используйте Personal Access Token:
# Создать: https://github.com/settings/tokens
# Scope: repo
```

#### Шаг 2: Render.com (5 минут)

1. **Зайдите на https://render.com**
   - Зарегистрируйтесь через GitHub

2. **Создайте Web Service**
   - New + → Web Service
   - Connect Repository: MySyte
   - Render обнаружит render.yaml автоматически

3. **Добавьте Environment Variables**
   ```
   TELEGRAM_BOT_TOKEN = (скопируйте из вашего .env файла)
   SECRET_KEY = (нажмите Generate)
   GEMINI_API_KEY = (скопируйте из .env, если используете)
   ```

4. **Create Web Service**
   - Деплой займет 3-5 минут
   - Получите URL: `https://[имя].onrender.com`

#### Шаг 3: Telegram бот (1 минута)

Откройте Telegram, найдите @BotFather:

```
/setdomain
@ZEVS_Parsing_orders_bot
[имя].onrender.com
```

(Без https:// и без /login!)

#### Шаг 4: Создание админа (2 минуты)

В Render Dashboard:
1. Откройте ваш сервис
2. Нажмите "Shell" (справа вверху)
3. Выполните:

```bash
python create_admin.py
```

4. Введите данные:
   - Telegram ID: `242165070`
   - Имя: любое
   - Остальное по желанию

#### Шаг 5: Тестирование

Откройте: `https://[имя].onrender.com/login`

Войдите через Telegram! 🎉

## 🆘 ПОДДЕРЖКА

### Если что-то не работает:

1. **Build failed на Render:**
   - Проверьте логи в Render Dashboard
   - Убедитесь что все Environment Variables добавлены

2. **"Bot domain invalid":**
   - Проверьте домен в @BotFather
   - Формат: `имя.onrender.com` (без https://)

3. **401 Unauthorized:**
   - Создайте администратора через Render Shell
   - Проверьте TELEGRAM_BOT_TOKEN

4. **Приложение не отвечает:**
   - Free plan: первый запрос после сна занимает 30-60 сек
   - Подождите немного

### Все еще проблема?

Откройте `DEPLOY_TO_RENDER.md` → раздел "🆘 Проблемы и решения"
