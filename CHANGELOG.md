# История изменений Parsing Taobao

## 06.08.2026 - Обновление проекта

### Переименование проекта
- Проект переименован с "My Site" на "Parsing Taobao"
- Обновлены все заголовки и названия в интерфейсе

### Новые функции

#### 1. Добавлены поля для товаров
- `product_url` - ссылка на товар на Taobao
- `product_image_url` - ссылка на изображение товара

#### 2. Улучшенный интерфейс "Мои заказы"
- Добавлена колонка с фотографиями товаров
- Миниатюры товаров (60x60px) с плавной анимацией при наведении
- Описание товара теперь является кликабельной ссылкой на страницу товара
- Иконка внешней ссылки для удобства

#### 3. Исправлена кодировка
- Правильное отображение китайских символов в названиях товаров
- UTF-8 кодировка для базы данных

### Технические изменения

#### База данных
- Добавлены новые поля в модель `Order`:
  - `product_url` (String, nullable)
  - `product_image_url` (String, nullable)
- База данных пересоздана с новой структурой

#### Интерфейс
- Обновлен HTML шаблон `index.html`
- Добавлены новые стили в `style.css`:
  - Стили для миниатюр товаров
  - Анимация при наведении на фото
  - Улучшенное отображение ссылок
  - Правильное отображение длинных названий товаров

#### Backend
- Обновлен тестовый эндпоинт `/api/test/add-order` с примером китайского названия
- Метод `to_dict()` модели `Order` теперь включает новые поля

### Как использовать

1. **Запустить сервер:**
   ```bash
   cd /Users/macprospodyrev/Projects/MySyte
   source venv/bin/activate
   cd backend
   python app.py
   ```

2. **Открыть в браузере:**
   ```
   http://localhost:8000
   ```

3. **Добавить тестовый заказ:**
   Перейдите по ссылке: http://localhost:8000/api/test/add-order
   
   Или нажмите "Добавить тестовый заказ" на главной странице

### Структура таблицы "Мои заказы"

| Колонка | Описание |
|---------|----------|
| Фото | Миниатюра товара с анимацией |
| ID заказа | Уникальный номер заказа |
| Описание | Название товара (на китайском) со ссылкой |
| Трек-номер | Номер отслеживания |
| Статус | Текущий статус заказа |
| Цена | Стоимость в юанях (CNY) |
| Дата заказа | Дата создания заказа |
| Обновлено | Последнее обновление |

### Примечания

- Если у заказа нет изображения, отображается placeholder с иконкой
- Если у заказа нет ссылки, название отображается обычным текстом
- Все китайские символы корректно отображаются благодаря UTF-8
