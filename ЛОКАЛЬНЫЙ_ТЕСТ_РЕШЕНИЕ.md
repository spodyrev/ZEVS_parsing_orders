# Решение проблемы с Telegram Login Widget на localhost

## Проблема
Telegram Login Widget **не работает** с `localhost` или `127.0.0.1` напрямую из-за ограничений безопасности Telegram.

## 🎯 Лучшее решение: Используйте ngrok

### Шаг 1: Установите ngrok

```bash
# Установка через Homebrew (рекомендуется для Mac)
brew install ngrok
```

Или скачайте с https://ngrok.com/download

### Шаг 2: Создайте публичный туннель

```bash
ngrok http 9000
```

Вы увидите что-то вроде:
```
Forwarding  https://abc123.ngrok.io -> http://localhost:9000
```

### Шаг 3: Настройте бот в @BotFather

1. Откройте @BotFather
2. `/setdomain`
3. Выберите `@ZEVS_Parsing_orders_bot`
4. Введите домен из ngrok: `abc123.ngrok.io` (без https://)

### Шаг 4: Откройте приложение через ngrok URL

Откройте в браузере: `https://abc123.ngrok.io/login`

**Теперь Login Widget должен работать!** ✅

## 🔄 Альтернатива: localtunnel (проще, но менее стабильно)

### Установка:
```bash
npm install -g localtunnel
```

### Запуск:
```bash
lt --port 9000
```

Вы получите URL типа: `https://random-name.loca.lt`

Используйте домен `random-name.loca.lt` в @BotFather

---

## ⚙️ Альтернатива 2: Деплой на бесплатный хостинг

Если не хотите возиться с туннелями, можно сразу задеплоить на бесплатный хостинг:

### Render.com (рекомендуется)

1. Создайте аккаунт на https://render.com
2. Подключите ваш GitHub репозиторий
3. Render автоматически задеплоит приложение
4. Получите публичный URL: `your-app.onrender.com`
5. Укажите этот домен в @BotFather

**Подробные инструкции:** см. `README_DEPLOYMENT.md`

---

## 🔍 Почему localhost не работает?

Telegram требует:
- ✅ Публичный домен с HTTPS
- ❌ Не работает: localhost, 127.0.0.1, локальные IP

Это сделано для безопасности - чтобы злоумышленники не могли украсть токены авторизации.

## 📋 Пошаговая инструкция с ngrok (самое простое)

```bash
# 1. Установите ngrok
brew install ngrok

# 2. Запустите туннель (в новом терминале)
ngrok http 9000

# 3. Скопируйте URL (например: abc123.ngrok.io)

# 4. Настройте бот
# Откройте @BotFather в Telegram:
#   /setdomain
#   @ZEVS_Parsing_orders_bot
#   abc123.ngrok.io

# 5. Откройте в браузере
# https://abc123.ngrok.io/login

# 6. Войдите через Telegram!
```

---

## ⚠️ Важно для ngrok

- **Бесплатный аккаунт:** URL меняется при каждом запуске
- **Платный аккаунт ($8/мес):** Можно зафиксировать домен
- **Для разработки:** Бесплатной версии достаточно

Каждый раз при запуске ngrok:
1. Получаете новый URL
2. Обновляете домен в @BotFather
3. Используете новый URL для входа
