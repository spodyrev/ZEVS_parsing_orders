## ⚙️ Как работает система

### 1. Конфигурация (`backend/config.py`)

```python
class Settings(BaseSettings):
    # Интервал синхронизации (в часах)
    sync_interval_hours: int = 2  ← 2 ЧАСА
```

**Можно изменить:**
- В файле `backend/config.py` (по умолчанию)
- Через `.env` файл: `SYNC_INTERVAL_HOURS=2`

### 2. Планировщик (`backend/scheduler.py`)

```python
class OrderSyncScheduler:
    def start(self):
        # Настраиваем задачу синхронизации
        self.scheduler.add_job(
            func=self.sync_orders,
            trigger=IntervalTrigger(hours=settings.sync_interval_hours),
            id='sync_orders_job',
            name='Синхронизация заказов с Taobao',
            replace_existing=True
        )
        
        # Запускаем планировщик
        self.scheduler.start()
        
        # Запускаем первую синхронизацию СРАЗУ
        self.sync_orders()
```

**Что происходит:**
1. Планировщик добавляет задачу с интервалом 2 часа
2. Запускается в фоновом режиме
3. Первая синхронизация выполняется **сразу** при старте
4. Последующие синхронизации - каждые 2 часа

### 3. Автозапуск (`backend/app.py`)

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
```

## 📅 График работы

### Пример запуска в 10:00:
```
10:00 → Запуск сервера
10:00 → Первая синхронизация (сразу)
12:00 → Вторая синхронизация (через 2 часа)

...и так далее каждые 2 часа
```

### Что происходит при синхронизации:
1. Получение заказов из Taobao (через сохраненные cookies)
2. Проверка каждого заказа в БД:
   - Если заказ **новый** → добавляется
   - Если заказ **существует** → обновляется (статус, трек-номер)
3. Логирование результатов

## ⏰ Расписание и производительность

### Нагрузка на Taobao API:
- **Интервал:** 2 часа
- **Запросов в сутки:** 12 (24 / 2)
- **Запросов в неделю:** 84
- **Запросов в месяц:** ~360

### Время синхронизации:
- **При наличии cookies:** ~5-15 секунд
- **При устаревших cookies:** Ошибка, требуется переавторизация
- **Без интернета:** Ошибка в логах

### Ресурсы:
- **CPU:** Минимально (фоновая задача)
- **RAM:** ~20-50 MB дополнительно
- **Сеть:** ~1-2 MB за синхронизацию

## 🔐 Требования для работы

### 1. Авторизация в Taobao
```bash
python3 auth_taobao.py
```
Создаст `taobao_cookies.json` с авторизационными данными.

### 2. Файл cookies должен существовать
```bash
ls taobao_cookies.json
# Если файл есть - OK
# Если нет - запусти auth_taobao.py
```

### 3. Cookies должны быть актуальными
Cookies истекают через ~7-30 дней. При ошибке:
```
⚠️ Заказы не получены
  2. Cookies устарели - повтори авторизацию
```
Запустить `python3 auth_taobao.py` заново.

## ❓ FAQ

### Q: Как проверить что синхронизация работает?
**A:** Посмотрите логи сервера или вызовите `/api/scheduler/status`

### Q: Можно ли запустить синхронизацию вручную?
**A:** Да! `POST /api/sync` или кнопка "Синхронизировать" на портале

### Q: Что если cookies устареют?
**A:** Синхронизация будет падать с ошибкой. Запустите `auth_taobao.py` для обновления

### Q: Как изменить интервал?
**A:** Измените `sync_interval_hours` в `config.py` или `.env`

### Q: Можно ли отключить автосинхронизацию?
**A:** Да, закомментируйте `scheduler.start()` в `app.py`

### Q: Синхронизация перезапишет данные склада?
**A:** Нет! Данные склада (`received_at_warehouse`, `warehouse_photo_path`) не трогаются
