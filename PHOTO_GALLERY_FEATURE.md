# 🖼️ Галерея фото со склада

## ✅ Что добавлено

Красивая галерея для просмотра фото прямо на портале с навигацией!

### Функции:

1. **Модальное окно** - фото открывается поверх страницы
2. **Навигация стрелками** - переключение между фото
3. **Клавиатурные сокращения** - ← → для навигации
4. **Счетчик** - показывает "2 / 5"
5. **Полный размер** - фото показывается в высоком качестве
6. **Скачивание** - кнопка для сохранения фото

## 🎯 Как работает

### 1. Клик на миниатюру
```
Пользователь кликает на фото в таблице
    ↓
Открывается модальное окно
    ↓
Загружается фото в полном размере
    ↓
Показывается информация о товаре
```

### 2. Навигация между фото
```
Кнопки: [◄] [►]
Клавиши: ← →
    ↓
Переключение на следующее/предыдущее фото
    ↓
Зацикливание (после последнего → первое)
```

### 3. Закрытие
```
Кнопка [Закрыть]
Клавиша: Esc
Клик вне окна
```

---

## ⌨️ Клавиатурные сокращения

| Клавиша | Действие |
|---------|----------|
| `→` | Следующее фото |
| `←` | Предыдущее фото |
| `Esc` | Закрыть галерею |

## 📋 Пример использования

### Сценарий 1: Просмотр одного фото
```
1. Склад отправил фото с номером: 113137930010
2. На портале: кликаете на миниатюру
3. Открывается модальное окно с большим фото
4. Информация: трек-номер, описание
5. Кнопки: [Закрыть] [Скачать]
```

### Сценарий 2: Просмотр нескольких фото
```
1. Склад отправил 5 фото с разными номерами
2. На портале: кликаете на первое фото
3. Открывается галерея: [1 / 5]
4. Нажимаете → или кликаете [►]
5. Показывается следующее фото: [2 / 5]
6. Продолжаете листать все 5 фото
```

### Сценарий 3: Быстрая навигация
```
1. Открыли фото
2. Нажимаете → → → (стрелки на клавиатуре)
3. Быстро пролистываете все фото
4. Нажимаете Esc для закрытия
```

## 🔧 Технические детали

### Модальное окно (Bootstrap 5)
```html
<div class="modal fade" id="photoModal">
  <div class="modal-dialog modal-xl">
    <!-- Большое модальное окно -->
  </div>
</div>
```

### JavaScript функции
```javascript
// Открыть галерею
openPhotoModal(orderId, trackingNumber, description)

// Навигация
navigatePhoto(direction)  // -1 = назад, +1 = вперед

// Показать фото
showPhoto()  // Загружает и показывает текущее фото

// Собрать фото
collectWarehousePhotos()  // Сканирует таблицу
```

### Автоматический сбор фото
```javascript
// При загрузке страницы
collectWarehousePhotos()

// Собирает все фото из таблицы:
warehousePhotos = [
  { orderId, trackingNumber, description, url },
  ...
]
```

## 🎨 Стили и анимация

### Модальное окно:
- Размер: `modal-xl` (большое)
- Позиция: центр экрана
- Анимация: плавное появление (fade)

### Изображение:
- Максимальная высота: 70vh (70% экрана)
- Адаптивное: `img-fluid`
- Скругленные углы: 8px

### Кнопки навигации:
- Позиция: слева и справа от фото
- Фон: светлый (btn-light)
- z-index: 1000 (поверх фото)

### Индикатор загрузки:
- Центр экрана
- Bootstrap spinner
- Скрывается после загрузки

## 📱 Адаптивность

### Десктоп (> 1200px):
```
- Модальное окно: 90% ширины экрана
- Фото: до 70% высоты экрана
- Навигация: большие кнопки
```

### Планшет (768px - 1200px):
```
- Модальное окно: 95% ширины экрана
- Фото: до 65% высоты экрана
- Навигация: средние кнопки
```

### Мобильный (< 768px):
```
- Модальное окно: 100% ширины экрана
- Фото: до 60% высоты экрана
- Навигация: компактные кнопки
```
