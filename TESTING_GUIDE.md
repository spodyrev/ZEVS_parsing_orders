# Быстрый старт - Тестирование Taobao интеграции

## 📋 Что нужно сделать

### 1. Убедись, что сервер запущен
```bash
./start.sh
```

Должен открыться браузер и веб-интерфейс на `http://localhost:8000`

### 2. Тестирование синхронизации заказов

#### Вариант A: Ручная синхронизация через API

1. Открой браузер на `http://localhost:8000`
2. В веб-интерфейсе нажми кнопку "Синхронизировать заказы"
3. Если это первый запуск:
   - Откроется окно браузера Playwright
   - Авторизуйся на Taobao
   - Нажми Enter в терминале после входа
   - Cookies будут сохранены автоматически

4. Проверь логи в терминале:
   ```
   🔄 Начало синхронизации заказов...
   Запрос к API: https://h5api.m.taobao.com/...
   Найдено X заказов в ответе API
   Успешно распарсено X заказов
   ✅ Синхронизация завершена: новых заказов: X, обновлено: Y
   ```

#### Вариант B: Автоматическая синхронизация

Планировщик запускается автоматически при старте сервера и будет синхронизировать заказы каждые 2 часа (по умолчанию).

### 3. Проверка результатов

#### В веб-интерфейсе (`http://localhost:8000`):
- Должна отобразиться таблица с заказами
- Статистика по статусам (Created, Paid, Shipped, Delivered)
- Можно фильтровать заказы по статусу

#### Через API:
```bash
# Получить все заказы
curl http://localhost:8000/api/orders

# Получить статистику
curl http://localhost:8000/api/stats

# Статус планировщика
curl http://localhost:8000/api/scheduler/status
```

## 🐛 Возможные проблемы

### Проблема 1: "API вернул ошибку"
**Причина**: Устаревшие или неправильные cookies

**Решение**:
```bash
# Удали старые cookies
rm taobao_cookies.json

# Перезапусти сервер
./start.sh

# Авторизуйся заново
```

### Проблема 2: "Не удалось распарсить заказ"
**Причина**: Структура API изменилась или отличается от примера

**Решение**:
1. Включи DEBUG логирование в `.env`:
   ```env
   LOG_LEVEL=DEBUG
   ```
2. Посмотри в логах raw JSON данные
3. Обнови парсер в `backend/scraper/parser.py`

### Проблема 3: "Подпись запроса неверна"
**Причина**: Неправильная генерация sign

**Решение**:
1. Проверь, что cookie `_m_h5_tk` существует
2. Проверь формулу: `md5(token&timestamp&appKey&data)`
3. Убедись, что timestamp в миллисекундах

### Проблема 4: "Заказов не найдено"
**Причина**: Нет заказов в аккаунте или API вернул пустой результат

**Решение**:
1. Проверь, что в аккаунте Taobao есть заказы
2. Посмотри логи - возможно API вернул ошибку
3. Попробуй изменить параметр `queryType` в `get_orders()`
