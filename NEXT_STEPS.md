## 🆘 Помощь

### Проблема: Бот не отвечает

**Решение:**
1. Проверьте что `python start_telegram_bot.py` запущен
2. Посмотрите логи: `tail -f logs/telegram_bot_*.log`
3. Перезапустите бота (Ctrl+C, потом снова запустить)

### Проблема: Трек-номер не найден

**Решение:**
1. Синхронизируйте заказы с Taobao:
   ```bash
   python update_tracking_numbers.py
   ```
2. Проверьте написание номера
3. Убедитесь что заказ есть в БД

### Проблема: Фото не сохраняется

**Решение:**
1. Проверьте права на папку:
   ```bash
   ls -ld warehouse_photos/
   ```
2. Создайте папку если нужно:
   ```bash
   mkdir -p warehouse_photos
   ```

## 🔧 Обновление: Исправление обработки нескольких фото

**Дата:** 6 августа 2026

### Проблема
При отправке нескольких фотографий (например, 5) с одним трек-номером бот обрабатывал только первое фото.

### Решение
Изменена логика обработки медиа-групп:
- Каждое новое фото отменяет предыдущую задачу обработки
- Обработка происходит только после получения всех фото (задержка 2 секунды)
- Все фото теперь сохраняются вместе

### Как использовать исправление

#### Способ 1: Быстрый перезапуск
```bash
cd /Users/macprospodyrev/Projects/MySyte
./restart_bot.sh
```

#### Способ 2: Ручной перезапуск
```bash
# Остановить старый бот (Ctrl+C в терминале где он запущен)
# Затем:
cd /Users/macprospodyrev/Projects/MySyte
source venv/bin/activate
python3 start_telegram_bot.py
```

### Тестирование
Отправьте боту 5 фотографий с одним трек-номером в подписи.
Ожидаемый результат:
```

✅ Успешно: 1
```
