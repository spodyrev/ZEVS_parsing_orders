## 🎨 Ключевые особенности дизайна

### 1. Типографика (Tesla Fonts)
**Основной шрифт:** Inter (семейство весов 300-900)
- Аналог фирменного шрифта Tesla "Gotham"
- Профессиональный, чистый, современный
- Отличная читаемость на всех размерах экранов

**Характеристики:**
- `-webkit-font-smoothing: antialiased` - сглаживание на macOS
- Letter-spacing: отрицательный для заголовков (-0.02em)
- Font-weights: от 300 (light) до 900 (black)

### 2. Цветовая палитра (Tesla Colors)
```css
--tesla-black: #171a20      /* Основной черный */
--tesla-dark-gray: #222222  /* Темно-серый */
--tesla-gray: #393c41       /* Серый для текста */
--tesla-light-gray: #5c5e62 /* Светло-серый */
--tesla-silver: #f4f4f4     /* Фон элементов */
--tesla-white: #ffffff      /* Белый фон */
--tesla-red: #e82127        /* Акцентный красный */
--tesla-blue: #3e6ae1       /* Синий для ссылок */
--tesla-green: #00b74f      /* Зеленый для успеха */
```

### 3. Философия дизайна
- **Минимализм:** только необходимые элементы
- **Чистота:** много белого пространства
- **Элегантность:** тонкие линии, мягкие тени
- **Функциональность:** красота через простоту

## 🎭 Анимации

### 1. Fade In Up (для карточек)
```css
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
Duration: 0.6s ease-out
```

### 2. Highlight (для новых заказов)
```css
@keyframes highlight {
  0% { background: rgba(62, 106, 225, 0.15); }
  100% { background: transparent; }
}
Duration: 2s ease-out
```

### 3. Hover Effects
- **Карточки:** translateY(-4px), увеличение тени
- **Кнопки:** scale(1.02)
- **Миниатюры:** scale(1.08)
- **Таблица:** Легкая подсветка строки

### 4. Transition Timing
```css
cubic-bezier(0.4, 0, 0.2, 1) /* Tesla's preferred easing */
```

## 🔧 Кастомизация

### Изменение цветов
Все цвета определены в переменных:
```css
:root {
  --tesla-black: #171a20;
  --tesla-red: #e82127;
  /* и т.д. */
}
```

### Изменение шрифта
Заменить в начале CSS:
```css
@import url('https://fonts.googleapis.com/css2?family=YourFont');
```
И обновить `font-family` в body.

### Изменение анимаций
Все transitions используют:
```css
transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
```
Можно изменить timing или easing function.
