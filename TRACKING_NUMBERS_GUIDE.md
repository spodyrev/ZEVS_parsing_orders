## 🚀 Как использовать

### Шаг 1: Запустить скрипт обновления трек-номеров

```bash
cd /Users/macprospodyrev/Projects/MySyte
source venv/bin/activate
python3 update_tracking_numbers.py
```

### Шаг 2: Что делает скрипт

Скрипт автоматически:
- Находит все заказы без трек-номера в базе данных
- Для каждого заказа делает запрос к API `mtop.taobao.order.query.detailv2`
- Извлекает трек-номер из поля `data.data.logisticsPackages.fields.packageInfos[0].mailNo`
- Обновляет заказ в базе данных
- Делает паузу 1 секунду между запросами (чтобы не нагружать API)

### Шаг 3: Просмотр результатов

После выполнения скрипта:

1. **В консоли** увидишь:
   ```
   ✅ Обновлено: 15
   ❌ Ошибок/не найдено: 5
   📊 Всего обработано: 20
   ```

2. **На веб-странице** (http://localhost:8000):
   - Обнови страницу (F5)
   - В колонке "Трек-номер" увидишь номера отслеживания
   - Если товар еще не отправлен, будет показан "-"

### 📝 Примечания

#### ⚠️ Если трек-номер не найден

Некоторые заказы могут не иметь трек-номера, если:
- Товар еще не отправлен продавцом
- Продавец не внес трек-номер в систему
- Это самовывоз или другой тип доставки

Это нормально и не является ошибкой.

#### 🔄 Автоматическое обновление

Чтобы трек-номера обновлялись автоматически при синхронизации заказов, можно модифицировать скрипт синхронизации, но это требует дополнительной работы.

Пока что просто запускай `update_tracking_numbers.py` после синхронизации заказов.

## 📊 Структура данных

### API endpoint
```
POST https://h5api.m.taobao.com/h5/mtop.taobao.order.query.detailv2/1.0/
```

### Параметры
```json
{
  "bizOrderId": "3316188865004009384"
}
```

### Путь к трек-номеру в ответе
```
data.data.logisticsPackages.fields.packageInfos[0].mailNo
```

### Пример трек-номера
```
79023797293946
```

## 🎨 Отображение в веб-интерфейсе

Трек-номера отображаются в таблице "Мои заказы":

| Фото | ID заказа | Описание | **Трек-номер** | Статус | Цена |
|------|-----------|----------|----------------|--------|------|
| 🖼️   | 331618... | Товар    | **79023797293946** | В пути | 59.46 CNY |

Если трек-номера нет, отображается "-".
