2 Вариант 2: Авторизоваться через локальный скрипт

Получите cookies авторизовавшись в Taobao

Требуется: Python 3.9+ и доступ к вашему компьютеру
  1. Откройте терминал на вашем компьютере 
    cd /Users/macprospodyrev/Projects/MySyte
source venv/bin/activate
  2. Запустите скрипт авторизации 
    python auth_taobao.py

    Откроется браузер. Войдите в ваш аккаунт Taobao.

  3. После успешной авторизации

    Файл taobao_cookies.json будет создан автоматически

  4. Загрузите файл через форму выше

    Используйте кнопку "Выбрать файл"
