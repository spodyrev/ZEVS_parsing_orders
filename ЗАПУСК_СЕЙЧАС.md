# Запуск прямо сейчас

## ✅ Все готово! Осталось 3 шага:

### Шаг 1: Установите зависимости

```bash
cd /Users/macprospodyrev/Projects/MySyte
pip install -r requirements.txt
```

### Шаг 2: Создайте первого администратора

```bash
python create_admin.py
```

**Что делать:**
1. Откройте Telegram
2. Найдите бота [@userinfobot](https://t.me/userinfobot)
3. Отправьте `/start`
4. Скопируйте ваш Telegram ID (это число)
5. Вставьте его в скрипт когда попросит

**Пример:**
```
Введите Telegram ID администратора: 123456789
Номер телефона (Enter для пропуска): +79001234567
Имя (Enter для пропуска): Ваше Имя
```

### Шаг 3: Запустите приложение

```bash
python backend/app.py
```

Вы увидите:
```
🚀 Запуск приложения...
✅ База данных инициализирована
🌐 Сервер доступен по адресу: http://127.0.0.1:8000
INFO:     Uvicorn running on http://127.0.0.1:8000
```

### Шаг 4: Откройте браузер

Откройте: **http://localhost:8000/login**

1. Нажмите "Login with Telegram"
2. Авторизуйтесь
3. Готово! Вы на главной странице

## ❓ Частые вопросы

**Q: Где взять Telegram ID?**  
A: [@userinfobot](https://t.me/userinfobot) → `/start`

**Q: Ошибка "Module not found"**  
A: `pip install -r requirements.txt`

**Q: Не могу войти**  
A: Проверьте что создали пользователя через `python create_admin.py`

**Q: Забыл создать админа**  
A: Запустите `python create_admin.py` в любое время
